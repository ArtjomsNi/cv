# 🐾 ВетОчередь — живая очередь для ветеринарных клиник

Общий сайт, где в реальном времени видно по каждой клинике:

- **очередь**: кто сейчас на приёме (номер → кабинет) и кто ждёт;
- **среднее время ожидания** за сегодня и **сколько ждать** тому, кто встанет в очередь прямо сейчас;
- **аппараты** (рентген, УЗИ, КТ…): работает / не работает и **есть ли сегодня специалист** для этого аппарата;
- **список цен**;
- **онлайн-консультации** с ветеринарами, которые работают из дома (видеозвонок через Jitsi Meet).

Клиент попадает в очередь тремя способами:

| Способ | Как работает |
|---|---|
| Регистратура | Сотрудник нажимает «+ В очередь» в кабинете клиники (client in), затем «Вызвать» и «Клиент ушёл» (client out). |
| Цифровая кнопка | Планшет у входа открывает страницу-киоск с большой кнопкой «Взять номер». |
| Физическая кнопка | ESP32 с кнопкой отправляет `POST /api/button/<ключ>` (прошивка в `device/`). |

Номер сразу появляется на общем сайте, на табло в зале ожидания (`display.html`) и у персонала.

**У каждого сотрудника каждой клиники свой логин.** Роли:

- **Суперадмин** — добавляет клиники и любых пользователей.
- **Админ клиники** — цены, аппараты, сотрудники своей клиники, ключ для кнопок.
- **Персонал** — очередь, статус аппаратов и специалистов, число врачей на приёме.
- **Удалённый ветеринар** — включает статус «в сети», принимает заявки на консультацию.

## Запуск

Нужен только Node.js 18+ (внешних зависимостей нет).

```bash
cd vet-queue
npm run demo      # с демо-данными: 2 клиники, 2 удалённых врача
# или
npm start         # чистая база; пароль суперадмина будет выведен в консоль
```

Откройте http://localhost:3000

Демо-логины (пароль `demo123`): `lapa-admin`, `lapa-reg`, `vet-ivars`, `vet-olga`. Суперадмин в демо: `admin` / `admin123`.

Переменные окружения:

| Переменная | По умолчанию | |
|---|---|---|
| `PORT` | `3000` | порт |
| `ADMIN_PASSWORD` | случайный | пароль суперадмина при первом запуске |
| `DATA_FILE` | `data/db.json` | где хранить данные |
| `APP_TZ` | `Europe/Riga` | часовой пояс («сегодня» для очереди и специалистов) |

Тесты: `npm test`.

## Физическая кнопка

1. В кабинете клиники → «Настройки и кнопки» скопируйте адрес вида `https://сервер/api/button/<ключ>`.
2. Впишите его и Wi-Fi в `device/esp32_queue_button/esp32_queue_button.ino`, прошейте ESP32 (Arduino IDE).
3. Кнопка — между GPIO 4 и GND. Светодиод мигает один раз — номер выдан, часто — ошибка.

Повторные нажатия чаще раза в 3 секунды игнорируются. Если ключ утёк — «Сгенерировать новый ключ».

Проверить без железа: `curl -X POST http://localhost:3000/api/button/<ключ>`

## Как считается ожидание

- **Ср. ожидание сегодня** — среднее время от получения номера до вызова, по всем вызванным сегодня.
- **Ждать ≈ сейчас** — (ожидающие + на приёме − свободные врачи) × средняя длительность приёма ÷ число врачей.
  Пока сегодня нет завершённых приёмов, длительность берётся 15 минут.
